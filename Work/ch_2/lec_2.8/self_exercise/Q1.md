# Question 1

## Question
What is Stochastic Gradient Descent (SGD), and how does it differ from Batch Gradient Descent?

## Answer
Stochastic Gradient Descent (SGD) is an optimization algorithm used to train machine learning models by updating model parameters after processing one training example at a time.

Difference:
- SGD updates weights after each sample.
- Batch Gradient Descent updates weights after processing the entire dataset.
- SGD is faster but noisier.
- Batch Gradient Descent is more stable but computationally expensive.
